# Dependencies for fleetpy_copilot.
#
# Single source of truth for everything the copilot needs beyond the Python stdlib
# and FleetPy's own `src`. The COPILOT CORE (generate/trace/provider(s)/validate/
# serialize/dryrun) is stdlib + `src` only and imports none of the packages below —
# it stays importable and testable under both conda and pip with nothing installed
# from here. These are needed only to (a) run the test suite and (b) run the service.
#
# Test suite:
pytest
hypothesis          # property-based tests in tests/test_value_properties.py
#
# Service tier (only imported by service.py / __main__.py, only when serving):
fastapi
uvicorn
httpx               # used by fastapi's TestClient in tests/test_service.py
